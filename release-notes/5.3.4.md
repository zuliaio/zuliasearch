# Zulia 5.3.4

A maintenance release focused on dependency currency and console logging. The CLI tools now start and log cleanly on Java 25.

## Bug Fixes

- **Range and numeric set queries on fields with the doc values skip index could skip or mis-score documents.** Lucene 10.5.1 fixes wrong run boundaries in `DocValuesRangeIterator` (GITHUB#16450) that affected bulk scoring on skip indexed fields.
- **Vector field merges rebuilt the HNSW graph from scratch.** Lucene 10.5.1 restores graph reuse during merges under per field vector formats (GITHUB#16400), which Zulia uses for every vector field. Merges of vector heavy shards are substantially cheaper.
- **gRPC log records bypassed the logging configuration.** gRPC logs through java.util.logging, which printed raw two line records to the console. All entry points now route JUL into the standard logging pipeline, so those records get the normal format and respect configured levels.

## Improvements

- **Console log color now follows the terminal.** Colored output appears only on an interactive terminal that supports ANSI. Piped and redirected output is plain, with no escape codes. Set `-Dzulia.log.color=true|false` to force either mode.
- **CLI tools start without JVM warnings on Java 25.** The native access warnings from Jansi and gRPC's Netty transport are resolved. The Jansi native library is gone entirely, and the start scripts grant native access the same way `zuliad` already did.
- **IndexWriter rollback no longer blocks on vector graph construction.** Lucene 10.5.1 checks for merge abort during HNSW builds (GITHUB#16367), improving shutdown latency on large vector segments.
