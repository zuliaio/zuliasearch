# Zulia 5.5.1

## New Features

- **Configure a spreadsheet source through `SpreadsheetSourceFactory`.** `fromFile`, `fromStream` and `fromSingleUseStream` accept a
  `Consumer<SpreadsheetSourceConfig>` that runs against whichever config the stream's type selects, so a caller can set the parsers,
  list delimiter or list handler without detecting the type. `DelimitedSourceConfig` and `ExcelSourceConfig` gain `withParsers(CellParsers)`.
- **New date cell parsers.** `CellParsers.flexibleIsoDateParser(ZoneId)` reads ISO date times and plain ISO dates such as `2024-05-01`,
  resolved strictly. `CellParsers.zuliaDateParser()` reads every date form a Zulia date field accepts, with UTC when no offset is given.
  `zuliaDateFormatter()` and `zuliaDates()` pair it with an ISO instant formatter. The default parsers are unchanged.
- **Ignore trailing blank header cells.** `HeaderConfig.ignoreTrailingBlanks(true)` drops blank header cells after the last named header,
  which previously became columns named `""`, `_2`, ... and failed strict headers. Off by default. Covers csv, tsv, xls and xlsx.

## Improvements
- **Signals usage reports tally activity per actor.** `UsageReport.tally` counts signals per actor for a list of `Activity` columns, an action optionally on one
  target type, with one search per activity. `forActivity` and `forActor` narrow any existing report to one activity or one actor.
- **Signals usage reports count up to 50,000 values per dimension, and the limit is configurable.** `UsageReports.maxFacetValues` sets it.
- **`ZuliaDateUtil` moved from `zulia-common` to `zulia-util`.** The package is unchanged and `zulia-common` depends on `zulia-util`, so
  existing imports still compile.

## Bug Fixes

- **An index settings update clears the shard query result caches.** A field mapping added, changed or removed on a live index now
  takes effect for the same query string immediately instead of after the next reader reopen.
- **A failed index commit no longer leaves a stale prepared commit flag.** The stale flag sent the next commit down the recovery
  branch, which could publish a document whose facet ordinal the committed taxonomy did not hold.
- **Associated document paths stay inside the index storage directory in single node mode.** A `..` segment in a unique id or filename could previously
  escape the data directory.
