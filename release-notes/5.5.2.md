# Zulia 5.5.2

## zulia-server

All of these apply to the file storage backend used for associated documents in single node mode. MongoDB and S3 storage are unchanged.

- New indexes bucket associated documents evenly and keep metadata under a `.meta` directory, so any filename is allowed.
- Existing indexes keep their layout and reject the reserved `.metadata` suffix.
- Metadata sidecars are written as extended JSON, so a `Long` reads back as a `Long`.
- An associated document id can no longer reach another id's directory through `..`.

## zulia-signals

- **Breaking:** `ActorActivity` is replaced by `ActorTally<Activity>`.
- Reports tally per actor by tag or field with `UsageReport.tallyBy`.
- Reports narrow to one tag or field value with `forTag` and `forField`.
- Date based time ranges: `TimeRange.since`, `days` and `month`, and `UsageReports.of` with a `LocalDate` or `YearMonth`.
- `SessionIds.hashed` derives a session id from a secret without storing it.
- `SignalsIndexConfig.indexTags` and `indexTag` replace `dimensions` and `dimension`, which remain deprecated for one release.
- Recording a signal never throws under `LOG_AND_DROP`. Validation failures are counted drops.
- A signal recorded after `close()` is logged as such instead of as a full queue.

## zulia-ai

- **Breaking:** embeddings change for the Nomic entries, Arctic queries, Jina small and inputs over 512 tokens on the 8192 token models. Re-embed indexes built with them.
- Embedding models tokenize to their real context length through a new `maxTokens` config option.
- Matryoshka slices are layer normalized and unit length.
- ONNX inputs bind by name, which fixes a swapped attention mask on the Nomic models.
- `SNOWFLAKE_ARCTIC_EMBED_M_V2` uses its `query: ` prefix.
- `JINA_SMALL_EN_V2` loads from the upstream export instead of the DJL zoo conversion.
- New embedding models `GTE_MODERNBERT_BASE` (Apache 2.0) and `MULTILINGUAL_E5_LARGE_INSTRUCT` (MIT).
- Large ONNX exports with an external weight file load without manual staging.
- The model downloader fetches `config.json` and reports every ONNX path tried on failure.
- Binary classifier training no longer crashes on the missing accuracy metric.
- Classifier stats report 0 instead of NaN, and both training paths share one early stop rule.
- A classifier that fails to load closes its model, and constant features scale to 0 instead of infinity.
